dry

A place where engines work: each one a model with a goal, tools and its own artifacts, stepping through phases until it replies, and asking you with real controls, not paragraphs. It runs entirely in this browser, against the model server you choose.

Open the app → Run locally with LM Studio

What is in it

✦

Engines

A model, a goal, a response contract and tools. A turn is steps until a reply; one step runs all its calls together. No step limit.

◇

Child engines

engine_call waits for a helper's reply; engine_start hears back later. Children share their level's context.

▤

Artifacts

Working material each engine keeps: plans, notes, files, terminals, shared feeds, what it learned. Every one is in the prompt as it is now.

⇢

Phases

A template lays out the prompt and the phases a run walks through, each with its own tools. Skills load when needed.

◐

Scenes

A living background, chosen apart from the theme: the jellyfish behind this page are the app's own abyss scene, drawn from the same code as the desktop window.

☑

A2UI asks

A reply can ask with a control: a choice, a few picks, yes or no, a calendar, a number, a field, a card to confirm.

⌂

Yours, local

State lives in this browser's IndexedDB. Nothing is sent anywhere but the model server you set. Keys never ship in the page.

⟁

One core

The same Rust core runs the desktop app, a server and this page (WebAssembly). Stores, models and hosts are traits with swappable parts.

Two ways to use it

Open the app

Load the demo to look around with no model at all: engines with a history, artifacts, a child engine, an open ask and an answered one.

Then point it at a model server in Settings → Models and send a message.

Run locally with LM Studio

  1. Install LM Studio and download a model.
  2. Open Developer, load the model and start the server (port 1234).
  3. In the server's Settings, turn on Enable CORS.
  4. Open the app, then Settings → Models → Detect; it picks the loaded model.
  5. Chrome asks once to let this site reach apps on your device (local network access): allow it.

Safari blocks an https page from calling http://localhost; use Chrome or Firefox, or serve the app from your own machine (see docs/browser.md).
