# Light+

Colour values of the editor default theme "Light+" (from the MIT-licensed theme-defaults in the open-source code editor's repo), mapped onto our tokens. Laid over `../overrides.md` while Code is shown; the same value in light and dark, so the page looks the same in either mode.
