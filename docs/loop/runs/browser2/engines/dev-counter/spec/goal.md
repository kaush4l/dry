Build a small counter widget as one HTML file: a number with +, - and reset buttons, dark, rounded, centered on the page.

## Scope
Create only the one HTML file in the project folder. No other files touched, no dependencies, no commit/push/publish. Stop and reply if anything outside this needs to change.
