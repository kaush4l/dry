## Goal
A small Python script that prints a center-aligned tree of height n, where each level has 2 more '*' than the level above it, for whoever runs it in the workspace.

## Scope
Create one script (e.g. tree.py) and prove it runs. Stop and reply if it needs anything beyond that. Never commit, push or publish.

## Done
The script prints a center-aligned tree of height n; level 1 has 1 star and each level adds 2 more (level k has 2k-1 stars); n is taken from the command line (default n=5 if none given); alignment is centered under the widest level. Prove it by running it for a few heights (e.g. n=1, n=3, n=5) and showing the output. Reply with Changed / Ran / Saw / Unverified / Also changed.
